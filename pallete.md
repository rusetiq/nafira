# Project Design System

## Color Palette

| Color Name | Hex Code | Where it's used |
| :--- | :--- | :--- |
| **Dark Background** | `#1b1b1b` | Scrollbar tracks, dark component backgrounds |
| **Charcoal** | `#2f2f2f` | Secondary dark backgrounds, card surfaces |
| **Base Body** | `#050505` | Main page background (`body`, `min-h-screen`), deep dark mode base |
| **Primary Accent** | `#f54703` | **Key Brand Color**: Icons, borders, primary buttons, text emphasis, selection highlights, shiny text gradients, `blob-1` animation |
| **Secondary Accent** | `#ff7518` | App shell radial gradients, background effects |
| **Glow Accent** | `#FD8B5D` | Shiny text animation, `blob-2` animation, gradient text, magic bento hover effects, scrollbar thumb |
| **Soft Accent** | `#FFC299` | `blob-3` animation, text gradients, cursor borders, glow pulse effects |
| **Body Text** | `#f8fafc` | Primary text content color |
| **White** | `#ffffff` | Headings, text highlights, shiny text gradients, glassmorphism borders (with opacity) |

## Typography

### Font Families
- **Display:** [Urbanist](https://fonts.googleapis.com/css2?family=Urbanist:wght@400;500;600;700;800;900&display=swap)
  - Used for: Headings, Shiny Text
  - Weights: 400, 500, 600, 700, 800, 900
- **Body:** [Inter](https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&display=swap)
  - Used for: Body text, UI elements
  - Weights: 400, 500, 600, 700
- **Grotesk:** [Space Grotesk](https://fonts.googleapis.com/css2?family=Space+Grotesk:wght@300..700&display=swap)
  - Weights: 300 - 700
- **Darker:** [Darker Grotesque](https://fonts.googleapis.com/css2?family=Darker+Grotesque:wght@300..900&display=swap)
  - Weights: 300 - 900
- **Bricolage:** [Bricolage Grotesque](https://fonts.googleapis.com/css2?family=Bricolage+Grotesque:opsz,wght@12..96,200..800&display=swap)
  - Weights: 200 - 800 (Variable optical size)
